# HdW-Labor – Touch panel prototype

- **`index.html`** – start page: switch between **Design A / B / C** and download the screenshots.
- **`panel/index.html`** – the panel itself (`?design=A|B|C`). All three designs share the same functions, taken only from the LV requirements (Crestron VC-4 on TS-770-B-S, 1280 × 800).
- **`DESCRIPTION.md`** – short description, page-by-page LV mapping and open assumptions.
- **`screenshots/`** – 25 screens per design; all in **`HdW_touch_panel_screenshots.zip`**.
- **`v1/`** – archive of the first mockup-only versions (not LV-compliant).

Phone link (once GitHub Pages is on): https://narti-live.github.io/hdw-touch-panel/
