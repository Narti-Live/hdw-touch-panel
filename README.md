# HdW Bochum – Touch panel web prototype

`index.html` is the whole app (one self-contained file, no internet needed).

**Open on a phone:** send `index.html` to the phone (AirDrop, e-mail, cloud drive) and open it in the browser, or host the folder on any web server. Hold the phone in landscape. On Android the ⛶ button gives full screen; on iPhone use Share → "Add to Home Screen" for a full-screen look.

- Buttons **A / B** at the left switch between the two designs (`index.html?design=B` opens B directly).
- Working: navigation, source dropdown, sliders, mute buttons, System ein/aus (with confirm and start-up delay), room switch (each room keeps its own settings), DE/EN, live clock (B), video call mock, screen cleaning lock.
- Settings are remembered in the browser. Prototype only, it does not control any device.
- `reference/` holds the two original mockups.
